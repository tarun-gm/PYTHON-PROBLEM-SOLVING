# Python Advanced Practice Portfolio

This repository contains 20 independent Python programs covering algorithms, data structures, automation-style utilities, data processing, and small application backends.

## Programs

1. Graph shortest path using Dijkstra's algorithm
2. Maze solver using breadth-first search
3. Least Recently Used (LRU) cache
4. Trie-based autocomplete
5. 0/1 knapsack optimization
6. Sudoku backtracking solver
7. In-memory text search index
8. Bank account and transaction simulator
9. SQLite inventory management
10. Duplicate file finder using SHA-256
11. Log level analyzer
12. Password strength checker
13. JSON record validator
14. Priority-based task scheduler
15. Sliding-window rate limiter
16. Safe arithmetic expression evaluator
17. Word frequency report
18. JSON-backed contact book
19. CSV sales analytics
20. Network topology analyzer

## Requirements

Python 3.10 or newer. The programs use the Python standard library only.

## Run a program

```bash
python 01_graph_shortest_path.py
python 06_sudoku_validator_solver.py
python 09_inventory_management.py
python 16_expression_evaluator.py
```

Some programs accept command-line arguments. Run `python PROGRAM_NAME.py --help` where applicable.

## Before publishing

Run each program, inspect the implementation, add your own test cases, and customize at least one meaningful feature. Be ready to explain the algorithm, data structures, trade-offs, and edge cases.
